# Расширения

Человек собирает помощника под свои нужды, а не получает всё сразу. Всё, что помощник умеет сверх ядра, — расширения трёх видов. Решение и правила безопасности — ADR-005 в `docs/DECISIONS.md`.

| Вид | `ExtensionKind` | Что это | Сейчас | Как ставится |
| --- | --- | --- | --- | --- |
| Навыки | `skill` | своя логика в составе приложения, без сети | задачи (`tasks`), калькулятор (`calc`) | встроены, включаются и выключаются |
| Подключения | `connector` | связь с внешним приложением (склад, expeora) | пока нет | кодом в составе приложения (`docs/CONNECTORS.md`) |
| Паки | `pack` | только содержимое, без кода: шутки, каламбуры, фразы | «Базовые шутки» (`jokes.basic`) | встроены в приложение или вставляются JSON-текстом |

Код навыков и подключений есть только в составе приложения: скачивать и запускать чужой код небезопасно и запрещено магазинами приложений. На лету ставятся только паки — это данные, они ничего не выполняют.

## Как включить и выключить

«Настройки → Расширения»: три группы — «Навыки», «Подключения», «Паки». У каждой строки название, описание, версия и автор, бейдж «встроено» и переключатель. Задачи выключить нельзя (бейдж «всегда включено», переключатель неактивен).

- Переключение применяется **сразу**, без перезапуска, и **ничего не сбрасывает**: задачи, история чата, выбранная задача, текст в поле ввода и ожидание подтверждения других коннекторов остаются. Снимается только ожидание подтверждения того коннектора, который выключили, — его «да» больше некому принять. Проверка — `test/home_page_test.dart`, группа «расширения включаются и выключаются без сброса».
- Выключенный навык не участвует в разборе сообщений: «2+2» при выключенном калькуляторе — обычное «не понял».
- Изначально включён минимум: задачи, калькулятор, базовый пак шуток.

### Как хранится выбор

В `settings.json` рядом с остальными настройками (`AppSettings`):

```json
{
  "reduce_motion": false,
  "show_timestamps": true,
  "disabled_extensions": ["calc"],
  "enabled_extensions": []
}
```

- `disabled_extensions` — выключенные из включённых по умолчанию;
- `enabled_extensions` — явно включённые из выключенных по умолчанию.

Поэтому новое расширение, включённое по умолчанию (`defaultEnabled: true`), после обновления приложения появляется включённым, даже если пользователь что-то выключал раньше. Битые значения (не список, не строки) читаются как пустые наборы и не мешают запуску.

### Код

`lib/core/extensions/`:

| Файл | Что в нём |
| --- | --- |
| `extension_kind.dart` | `ExtensionKind` — `skill`, `connector`, `pack` |
| `extension_info.dart` | `ExtensionInfo` (паспорт для настроек), `ExtensionChoice` (выбор пользователя) |
| `extension_registry.dart` | `ExtensionRegistry` — все навыки, подключения и паки, выбор, `enabledConnectors` для маршрутизатора, `packEntries` для навыков |
| `pack.dart` | `Pack`, `PackEntry`, `PackPersona`, `PackStyle`, `PackFormat` — формат и строгая проверка |
| `pack_store.dart` | `PackStore` — встроенные и пользовательские паки, импорт, удаление |

Навыки и подключения реализуют обычный интерфейс `Connector`; вид, версия, автор, `defaultEnabled` и `required` — поля `ConnectorInfo` (`docs/CONNECTORS.md`). Регистрация — `lib/main.dart`:

```dart
final extensions = ExtensionRegistry(
  connectors: <Connector>[
    TasksConnector(taskService: tasks, parser: ScenarioParser(clock: clock)),
    const CalculatorConnector(),
  ],
  packs: PackStore(loadBuiltIn: _builtInPacks, userDirectory: '<документы>/assistant/packs'),
);
final assistant = AssistantController(extensions: extensions, clock: clock);
```

`AssistantController(connectors: …)` по-прежнему работает: тогда все коннекторы включены. `HomePage` применяет выбор из настроек к `assistant.extensions` при запуске и при каждом изменении.

## Паки

Пак — один JSON-файл. Встроенные лежат в `assets/packs/*.json` (каталог зарегистрирован в `pubspec.yaml`), пользовательские — в `<документы приложения>/assistant/packs/<id>.json`. Добавить пак: «Настройки → Расширения → Добавить пак», вставить текст файла. Если пак с таким id уже установлен, помощник спросит, заменить ли его. Пользовательский пак можно удалить («Удалить» с подтверждением), встроенный — только выключить. Удалённый пак забывается и в выборе пользователя: если добавить его снова, он придёт включённым; замена пака новой версией выбор сохраняет.

Паки сохраняются на диск компактным JSON (без отступов, без `"persona": "any"`), поэтому сохранённый файл не больше вставленного текста и проходит предел 1 МБ при следующем запуске. Проверка «такой id уже есть» и запись файла — одна операция в общей очереди: два одновременных импорта одного нового id не пройдут оба без подтверждения. Ошибка записи (нет места, нет доступа) показывается в диалоге текстом, пак не принимается. Удаление стирает именно тот файл, из которого пак загружен, даже если имя файла не совпадает с id.

### Формат `assistant-pack/1`

```json
{
  "format": "assistant-pack/1",
  "id": "jokes.office",
  "type": "jokes",
  "title": "Офисные шутки",
  "author": "Мария",
  "language": "ru",
  "version": "1.0.0",
  "description": "Про планёрки, отчёты и кофе.",
  "entries": [
    {
      "id": "j1",
      "text": "Планёрка прошла продуктивно: запланировали следующую планёрку.",
      "tags": ["планёрка", "задачи"],
      "persona": "any",
      "styles": ["friendly", "neutral"]
    },
    {
      "id": "j2",
      "text": "Кофе — это способ превратить «не могу» в «уже делаю».",
      "tags": ["кофе"],
      "persona": "noda"
    }
  ]
}
```

| Поле | Обязательно | Правило |
| --- | --- | --- |
| `format` | да | ровно `assistant-pack/1`; другая версия — «Версия формата … не поддерживается» |
| `id` | да | `[a-z0-9][a-z0-9._-]{1,63}`: 2–64 символа. Не совпадает с id встроенного пака и с id навыка или подключения (`tasks`, `calc`) |
| `type` | да | `jokes`, `puns` или `phrases`; другой вид отклоняется с перечнем поддерживаемых. Новый вид добавляется в `PackFormat.types` вместе с навыком, который им пользуется |
| `title`, `author` | да | непустые строки до 100 символов |
| `language` | да | пока только `ru` |
| `version` | да | вида `1.0.0` |
| `description` | нет | строка до 500 символов |
| `entries` | да | непустой список, не больше 5000 записей |
| `entries[].id` | да | `[a-z0-9][a-z0-9._-]{0,63}`, уникален в паке |
| `entries[].text` | да | непустая строка до 500 символов |
| `entries[].tags` | нет | до 10 меток, каждая — непустая строка до 30 символов; хранятся в нижнем регистре, «ё» → «е» |
| `entries[].persona` | нет | `any` (по умолчанию), `rio` или `noda` |
| `entries[].styles` | нет | подмножество `neutral`, `friendly`, `brief`, `business`; пусто — любой стиль |

Общие правила проверки (`PackFormat.parse`):

- файл не больше 1 МБ, это JSON-объект;
- неизвестные поля — ошибка (и на верхнем уровне, и в записях): опечатка в имени поля не теряется молча;
- типы строгие: строка должна быть строкой, список — списком;
- метка порядка байтов (BOM) в начале текста допускается и отбрасывается;
- управляющие символы (кроме перевода строки и табуляции) и знаки направления текста (U+200E, U+200F, U+202A–U+202E, U+2066–U+2069, U+061C) запрещены во всех строковых полях, включая метки: иначе название могло бы показаться в настройках задом наперёд;
- ошибки — по-русски, с местом: «entries[3]: текст длиннее 500 символов.»; проверяются все записи, показываются первые 20 и «И ещё ошибок: N.» с настоящим числом остальных;
- пак, не прошедший проверку, не сохраняется. Битый файл в каталоге паков пропускается при запуске и не мешает остальным (`PackStore.loadErrors`).

Текст записи — только текст. Он ничего не выполняет и не читается как разметка: `<b>`, `**` и `${…}` показываются как есть.

### Как паки будут использоваться

Сейчас паки только перечисляются в настройках. Будущие навыки (беседа, шутки по просьбе, каталог ответов) берут записи через реестр — только из включённых паков:

```dart
final jokes = extensions.packEntries(
  type: 'jokes',
  tags: <String>{'понедельник'},   // все метки должны быть у записи
  persona: PackPersona.noda,        // any подходит обоим помощникам
);
```

Выбор записи — детерминированный (как варианты каталога ответов в `docs/PLANS.md`), стиль общения сужает выбор по `styles`. `PackStore.entries` даёт то же без учёта выбора пользователя (для предпросмотра и тестов).

## Навык «Калькулятор»

`lib/core/skills/calculator/`: `CalculatorConnector` (id `calc`, команда `calc.evaluate`), разбор и счёт — `Calculator`, точные числа — `Rational`.

- Понимает цифры с запятой или точкой, разряды через пробел («2 400»), `+ - * / × ÷ : ^ **`, скобки, унарный минус, `%`, `√`; слова «плюс», «минус», «умножить на», «умножь на», «помножить на», «разделить на», «поделить на», «делить на», «в степени», «в квадрате», «в кубе», «корень из», «квадратный корень из»; «X% от Y», «Y плюс/минус X%»; «умножить 3 на 4»; числа словами от «ноль» до «девятьсот», «тысяча» («двадцать пять», «две тысячи»), в том числе в родительном падеже («15% от двухсот», «корень из шестнадцати»); проценты со знаком и после множителя («−15% от 200» = −30, «10 × 15% от 2400» = 3 600); тире «—» как минус. «Корень из 1/4» словами — корень из дроби (0,5), знак «√1/4» — по правилам, (√1) / 4.
- Маркеры: «сколько будет …», «посчитай …», «вычисли …», «реши …», «рассчитай …», «чему равно …», «… равно?», «=» в конце. С маркером — уверенность 0.9, сообщение целиком — пример — 0.85 (нужно хотя бы одно действие: операция, корень, степень, «% от»).
- Не примеры: даты «12.11», время «18:30» и «в 10», одиночные числа и артикулы, диапазоны «10-15 минут», телефоны «+7 999 123-45-67» и «8-800-555-35-35», версии «2.10», метки, задачи с числами («купить 2 кг муки», «добавь задачу 2+2»), «через 2 часа». Без маркера не считаются и целые числа, сцепленные вплотную «-» или «/» без других знаков: артикулы «64115-01», «64115/2», телефоны «555-1234», диапазоны «10-15», «2–3», даты «12/11», «05/11/2026», «24/7». С пробелами («10 - 15»), с другими знаками («2+10/5») или с маркером («посчитай 24/7») это пример. Двоеточие вплотную отбрасывается, только если похоже на время («18:30», «9:05»): «2,5:0,5» и «100:4» — деление. Двойное отрицание «−(−3)» — пример, одно «−3» — нет.
- Счёт точный: рациональные числа на `BigInt`; корень точный для полных квадратов, иначе приближённо с «≈»; дробная степень — приближённо. Никакого `eval`.
- Ответ: «2 + 2 × 2 = 6», «15% от 2 400 = 360», «10 / 3 ≈ 3,333333333» (10 значащих цифр), «1 / 8 = 0,125». Конечная дробь длиннее 20 знаков после запятой пишется точно с порядком, без «≈», если в ней не больше 20 значащих цифр: «10^−21 = 1 × 10^−21», «1 / 2^21 = 4,76837158203125 × 10^−7». Ошибки: «На ноль делить нельзя.», «Получается слишком большое число — такое не посчитаю.», уточнение «Не понял пример. Например: «сколько будет 15% от 2400».».
- Пределы: пример до 200 символов (длина проверяется до любого разбора, так что длинная вставка не тормозит), скобки до 20 уровней, целая степень до 1000 по модулю, не больше 1000 цифр в числителе и знаменателе результата («10^999» считается, «10^1000» и «10^−1000» — «слишком большое число»). Приближённый счёт идёт в `double`: что больше ~1,8 × 10^308, тоже «слишком большое число».

Проверки: `test/skills/calculator_test.dart` (ответы, пределы, не примеры, совместная работа с задачами) и корпус `test/corpus/calc.jsonl` — там у строк калькулятора есть поле `answer` с ожидаемым ответом (`docs/CORPUS.md`).
