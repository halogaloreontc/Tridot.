# Chat-first UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать тёмный минималистичный chat-first интерфейс с капсульными действиями, скрываемой панелью задач, рабочим контекстом и автоматической прокруткой.

**Architecture:** Состояние остаётся в `HomePage`; `AssistantController`, `TaskService` и `TaskRepository` не меняются. Визуально независимые виджеты выделяются из `home_page.dart`, тема централизуется в `assistant_theme.dart`. Панель использует `Scaffold.endDrawer`; статистика и новые журналы не добавляются.

**Tech Stack:** Dart `>=3.4.0 <4.0.0`, Flutter Material, `flutter_test`; новых зависимостей нет.

**Spec:** `docs/superpowers/specs/2026-11-03-chat-ui-design.md`

## Global Constraints

- Глубокий чёрный фон, капсульные действия, приглушённый акцент, минимум теней.
- Панель задач закрыта по умолчанию на desktop и Android.
- Не добавлять фиктивную статистику, телеметрию, историю команд или state management.
- Не менять публичные `TaskService`, `TaskRepository`, сценарии и JSON.
- Все отображаемые действия должны работать; быстрый шаблон не отправляется автоматически.
- Для каждого нового поведения сначала failing widget test, затем минимальная реализация.
- Не запускать tag/manual Android Release ради проверки; обычный `push` должен вызывать только `verify`.

## Review Focus

- Пустой список задач: панель открывается, но контекст выбранной задачи отсутствует; покрывается Task 1.
- Выбор задачи: строка контекста соответствует именно нажатой задаче; покрывается Task 2.
- Быстрый шаблон: текст подставляется без отправки; покрывается Task 2.
- Маленькое окно и длинный диалог: последний ответ виден; покрывается Task 2.
- Повторный запуск: UI-выбор не восстанавливается, JSON продолжает хранить задачи; проверяется Task 3.
