## Слои понимания

Помощник понимает фразу последовательными слоями. Каждый отвечает на свой
вопрос, и действие выполняется только тогда, когда его пропустили все слои.
Решение должно объясняться: помощник может показать, как он понял фразу.

| Слой | Вопрос | Что делает |
|---|---|---|
| 1. Нормализация | Что написано? | Регистр, «ё», латинские буквы-двойники, опечатки; числа-коды (артикул 64115) не путаются с датой и временем. |
| 2. Ассоциации | Что это значит? | Словарь связей «звонок ≈ позвонить», «остаток ≈ сколько ≈ наличие»: общий и свой у каждого коннектора, с весами. |
| 3. Распознавание | Какая команда? | Каждый коннектор оценивает фразу (команда и уверенность 0..1). |
| 4. Контекст | О чём сейчас разговор? | Выбранная задача, последний коннектор, предыдущие реплики меняют оценку. |
| 5. Решение | Уверен ли я? | Выше порога — действие; два близких варианта — вопрос «какой из»; ниже порога — уточнение. |
| 6. Проверка перед действием | Можно ли? | Объект существует, права есть; любое изменение данных во внешнем приложении — только после подтверждения пользователя. |
| 7. Ответ | Что сказать? | Только из настоящих данных, с пометкой «понял как: …». |
| 8. Обучение (вне приложения) | Где ошибаюсь? | Генератор фраз, корпус, `known_gap`, подбор весов и порогов. |

## Расширения: Связной под себя

Человек настраивает Связной под свои нужды, а не получает всё сразу. Общее
название — «Расширения», три вида:

| Вид | Что это | Примеры | Как ставится |
|---|---|---|---|
| Навыки | своя логика без сети | задачи, калькулятор, таймеры, беседа | встроены, включаются и выключаются |
| Коннекторы | связь с внешним приложением | halowarekeep, expeora | кодом в составе приложения или по описанию `assistant.json` |
| Паки | только содержимое, без кода | шутки, каламбуры, стили, словари ассоциаций, тематические фразы | из файла или по ссылке, как паки «Своей игры» |

- В интерфейсе коннекторы — раздел «Подключения» («подключить склад»).
- На лету ставятся только паки и коннекторы по описанию: это данные, они
  ничего не выполняют. Код коннекторов — только в составе приложения
  (скачивать и запускать чужой код небезопасно и запрещено магазинами).
- Изначально включён минимум: задачи, калькулятор, беседа, базовый пак шуток.
- Пак: название, автор, язык, записи с метками (тема, для Liorio/Noda, стиль).
  Паков может быть несколько; пак или отдельную запись можно выключить.
- «Настройки → Расширения»: включённое, установленное, доступное.

### Роли: следующие

- **«Продавец expeora»** — вторая роль: слот `ConnectionSlots.expeora`
  (тот же `ManifestConnector`), свои кнопки («Заказы сегодня», «Остаток
  по артикулу»), подсказки маршрутизации и самоописание («с продажами»),
  встроенное описание expeora — главное, как у склада. Перед этим —
  прочитать код expeora и дописать его действия входа в
  `ManifestDescription.authActions`.
- **Мастер адаптеров** (для сторонних API без своего `assistant.json`):
  OpenAPI, коллекция Postman или примеры запросов и ответов → черновик
  адаптера `assistant/1` (команды, `api.only` только из чтений, шаблоны
  ответов) → локальные модели генерируют фразы (`tools/corpus_gen`) →
  проверка корпусом (перехваты задач, беседы, калькулятора) → пак
  адаптера. Адаптер — данные, проверяется так же строго, как описание с
  сервера; права — только чтение, запись — по ADR-004 с подтверждением.
- Роль из пака (только данные: набор id навыков, кнопки, самоописание) —
  после того как появятся роли сторонних авторов; подсказки маршрутизации
  — только из встроенного списка.

## Навык «Пароли» (следующий)

**Ноябрь 2026 (ADR-025):** мастер-пароля больше нет — сейф защищён ключом устройства (Android Keystore; DPAPI на Windows; файл на macOS и Linux) и кодом восстановления, который показывается один раз; ПИН-код сейфа и «Сейф по отпечатку / Face ID» — по желанию в «Сейф → Настройки → Вход в сейф»; «Вход в приложение по отпечатку / Face ID» — в «Настройки → Защита». Старые сейфы переходят на это после одного ввода мастер-пароля. Дальше: зашифрованная копия на облачный диск, Keychain/Secret Service на компьютере, Windows Hello и Touch ID для входа в приложение.

Включаемый навык вне ролей: сейф паролей с подсказками на устройстве и помощь, когда пароль забыт. Проект готов, решения владельца приняты:
- хранятся сайт, логин, пароль, заметка и подсказка; шифрование на устройстве, наружу ничего не уходит;
- открытие мастер-паролем; на Android и macOS — ещё отпечатком (на macOS после подписи командой); на Windows только мастер-пароль; автозапирание;
- забыт мастер-пароль, но отпечаток работает (Android, macOS) — можно задать новый;
- подсказка и пароль — только во временной карточке, в историю чата не попадают; логин в ответах — в маске;
- в v1: генератор (только английский словарь EFF large, 7776 слов; русских режимов — раскладки, транслита, кириллицы — нет: «русскоязычный мало где используется»), проверка слабых, повторяющихся и старых паролей, зашифрованная резервная копия и перенос, импорт CSV браузера, тренировка памяти.
- готово (этап 3, часть 1): генератор (слова EFF и символы, `randombytes` + отбраковка, энтропия видна), оценка надёжности (частые пароли SecLists, ряды QWERTY/ЙЦУКЕН, даты 1940–2035, русское слово в английской раскладке, l33t, данные записи), «Проверка» (в чат — только числа), `HintGuard`, лестница подсказок и «Проверить себя», тренировка важных записей.
- готово (этап 3, часть 2): импорт CSV из Chrome/Edge/Яндекса, Firefox, Safari, Bitwarden, KeePassXC и ручное сопоставление колонок (свой разборщик RFC 4180, Windows-1251 по вопросу, предпросмотр «новая / дубль / дубль с другим паролем», по умолчанию «оставить обе»; враждебный CSV: пределы длины, управляющие символы и символы направления текста, только `http`/`https`/`android://`, хост в punycode, пароли в колонке «Название»/«Логин» — отказ, подсказки и «Важный» из файла не берутся); резервная копия `.relaybak` (свой ключ и соль, Argon2id не слабее хранилища, проверка чтением, мастер-пароль или отдельный пароль копии) и восстановление: «Создать сейф из копии», слияние по `entry.id` и (сервис, логин) с выбором «оставить обе / из копии / текущую», «Заменить всё» — текущее в архив. Копия — недоверенные данные: только записи и `k_fp`, производные поля пересчитываются. Выбор файла — свой, на `dart:io` (без нового нативного пакета). Дальше (этап 4): `file_selector` (пакет уже в приложении для вложений сессий, ADR-019; импорт и копии пока на своём выборе)/`share_plus`, напоминание о копии, тренировка пароля копии и мастер-пароля.

## Tridot: Связной, Лиорио и Нода

Решение владельца: приложение называется **Tridot** (по-русски «Тридот»),
главный помощник — **Связной** (в женском роде — **Связная**; до ADR-017 —
«Садо»), у него два помощника с разными обязанностями.
Порядок: после боковой панели «Ж1», до расширений.

- **Связной — главный.** Беседа, задачи, планирование, калькулятор. Встречает в
  новой сессии и передаёт фразу помощнику, если она из его зоны. Пол
  выбирается в настройках (ответы и так склоняются по роду), по умолчанию —
  на выбор при первом запуске.
- **Лиорио — расширения.** Склад (вопросы и действия с карточкой
  «Подтвердить»), пароли, конвертер, архиватор, загрузчик видео, будущие
  подключения.
- **Нода — оповещения.** Напоминания, просрочки (строка на экране новой
  сессии), сигналы склада (действие ждёт подтверждения, жалоба), итоги
  фоновых задач, утренняя сводка.
- **Режимы** («Мой Связной» → «Помощники»): **Соло** — Связной делает всё сам;
  **Дуэт** — Связной и один помощник на выбор, зона второго возвращается к
  главному; **Трио** — все трое. Переход: кто был в дуэте Лиорио + Нода — Трио.
- **Под себя.** Каждого можно переименовать, выбрать пол и переназначить
  обязанности (какой помощник ведёт расширения, какой — оповещения).
  Обращение по имени («Нода, …») берёт имена из настроек, а не из кода; имя,
  совпадающее с обращением к подключению («склад», «пароли»), не
  принимается — иначе «склад, где лежит…» ушло бы не туда.
- **Вид.** Метка над ответом — кто ответил (С, Л, Н). Цвета: Лиорио
  лазурный (пастельный), Нода нежно-розовая, Связной — третий акцент П1 (фиолетовый, подобрать
  контрастный: на тёмном фоне не ниже 4.5:1). Знак приложения — три точки
  цветами помощников.
- **Имя приложения.** «Tridot» на плашке меню, в заголовке окна, в названии
  на телефоне и в магазине; карточка «Мой Связной» → «Мой Связной».
  `applicationId` и имя пакета не меняются (обновление поверх установленной
  версии). Перед выпуском проверить, что имя свободно в Google Play и что
  есть домен.
- **Ответы.** Каталог ответов получает голос главного во всех стилях; записи,
  где Лиорио или Нода говорят о себе, проверяются на новые обязанности.
  Склад больше не «Нодин»: тексты про склад — от Лиорио, сигналы — от Ноды.
- готово (ADR-016): модель и настройки (`PersonaCast`, режимы, обязанности,
  переход со старых настроек, запись старых ключей для отката, проверка
  имён), маршрутизация по зонам и ответы голосом главного во всех стилях,
  «Мой Связной» → «Помощники» (режим, имена, пол, стиль, обязанности),
  карточка выбора пола главного, метки С/Л/Н, фиолетовый Связной с проверкой
  контраста, знак из трёх точек в меню и на иконках запуска, название Tridot
  в интерфейсе и нативных обёртках (Android, macOS, Windows, Linux; каталогов
  `ios/` и `web/` нет). До выбора пола ответы главного — в мужском роде.
- готово (ADR-017): главный по умолчанию — «Связной» или «Связная» по
  выбранному роду; переименовать можно в «Помощниках» (своё имя от рода не
  зависит). Обращение «Связной, …» и «Связная, …» при любом роде, падежи
  в беседе («сделай Связного основным», «дуэт со Связным»), падежи своих
  имён («сделай Свету основной»). Карточка первого запуска — «Связной или
  Связная?». Кто называл главного «Садо» по умолчанию, видит новое имя;
  своё имя остаётся.
- открыто (владелец): проверить, что имя свободно в Google Play, и домен.

## Голосовой ввод (Vosk) — сделано (ADR-023)

Решение владельца: только ввод, без ответов голосом; после блока «Связной,

- [x] Распознавание офлайн через Vosk (`dart:ffi` к libvosk из AAR,
  arm64), маленькая русская модель (~45 МБ). В сборку не входит:

  предложении; переадресации только в пределах сайта; нехватка места —
  отдельная ошибка, проверенный архив не скачивается заново.
- [x] Нажать на микрофон — говорить, нажать ещё раз («стоп») — текст в
  поле ввода с подсветкой распознанной команды; правка перед отправкой.
  Настройка «Отправлять сразу» (похожее на пароль сразу не уходит).

## Расширения: конвертер, архиватор, загрузчик видео

После переноса навигации. Все три выключены по умолчанию и включаются в «Расширениях». Решения владельца:

Состояние: ✔ шаг 1 — общая карточка-форма, исполнитель задач и архиватор целиком; ✔ шаг 2 — конвертер; ✔ шаг 3 — загрузчик видео (ADR-024).
- **Конвертер: списки и качество, медиа на телефоне и Mac (ADR-026).** Решение владельца: «во что» и действие архиватора — выпадающим списком; у фото, видео и звука — качество («с mp4 в mp3 320 кбит/с»); конвертер на телефоне и Mac; LAME встраивается.
  - ✔ S1: выпадающие списки во всех карточках; цели m4a, wav, mov и «пережать» свой формат; битрейт звука, размер и качество видео, качество JPEG и уменьшение картинок; «Сжатие» архиватора; последний выбор запоминается; фразы «в mp3 320», «в mp4 720p», «сожми фото до 1920»; честные отказы для WebM на телефоне и Mac и для FLAC/OGG/Opus.
  - ✔ S2: Android — MediaExtractor/MediaCodec/MediaMuxer, Media3 Transformer для MP4 и встроенный LAME 3.100 (`packages/tridot_lame`, libtridot_mp3.so, JNI): mp3, m4a, wav, mp4, кадр; ход работы и отмена. На телефоне не проверено.
  - ✔ S3: macOS — AVFoundation (`macos/Runner/MediaChannel.swift`, `MediaPipelines.swift`) и тот же LAME (tridot_mp3.framework, dlopen): mp3, m4a, wav, mp4, mov, кадр; лицензии (раздел LAME в NOTICE, экран лицензий), ADR-026. Swift не собирался: в контейнере нет Xcode — нужна сборка и проверка на Mac.
  - ✔ Правки по ревью (ADR-026, «Уточнения после проверки»): буфер MP3 при пересэмплировании 8–24 кГц, свой `.part` у каждого запуска, честные причины «нет кодировщика» и «Mac не открывает этот файл», Inter и высота выпадающего списка, «в формат mp3 320», адрес исходников LAME в NOTICE.
  - Дальше (вопросы владельцу, ADR-026): служба переднего плана для долгих конвертаций на телефоне; ogg/opus на Android 10+; TAR.GZ в архиваторе; WebP как цель картинок; LAME 4.0; проверка на телефоне и на Mac (в том числе запись `….part` рядом с файлом из окна сохранения в песочнице).
- **Конвертер.** ✔ Сделано (ADR-024, шаг 2): картинки — на всех платформах; звук и видео через скачиваемый ffmpeg — на Windows и Linux. На Android и macOS ffmpeg нет (запрет запуска скачанных программ на Android 10+; нет LGPL-сборки с lame, песочница на Mac) — там звук и видео делают средства системы и встроенный LAME (ADR-026). Подписи у сборок ffmpeg нет — проверка по закреплённой SHA-256.
  - Звук и видео: wav/flac/ogg/m4a → mp3, mp4/webm/mkv → mp3 (звуковая дорожка), видео → другое видео.
  - Картинки: png/jpeg/webp/bmp/gif → png/jpeg. Можно вынуть кадр из видео в jpeg/png.
  - Картинки конвертируются на Dart, без ffmpeg.
  - ffmpeg **не встраиваем в сборку**: он скачивается один раз при включении расширения. Файл проверяется по контрольной сумме и подписи, приложение предупреждает об объёме. Без ffmpeg работают только картинки. Сборка ffmpeg — LGPL, с libmp3lame.
- **Архиватор.** ✔ Сделано (ADR-024); перетаскивание в карточку не подключено — desktop_drop ломает сборку APK (ADR-024), на компьютере — «Выбрать файлы» и «Выбрать папку».
  - Только **ZIP**: создание (в том числе папки целиком), распаковка, просмотр содержимого. На чистом Dart, пакет `archive`.
  - Защита от «zip-бомб» и путей вида `../`: пределы размера и числа файлов, распаковка только внутрь выбранной папки.
  - RAR, 7z и ZIP с паролем — не в первой версии.
- **Загрузчик видео по ссылке** (YouTube и соцсети). ✔ Сделано (ADR-024, шаг 3) на Windows и Linux. На Android — **не сделано ни в одной сборке**: yt-dlp нужен Python, а запуск скачанных программ Android 10+ запрещает; без встраивания интерпретатора не обойтись — решение за владельцем (ADR-024, «Открытые вопросы»). На macOS — нет (песочница, карантин). В сборке для Google Play (`--dart-define=TRIDOT_STORE=play`) загрузчика нет.
  - Работает через `yt-dlp`, нужна сеть. Платформы: Windows, macOS, Linux и Android-сборка вне Google Play. В версии из Google Play расширения нет: магазин такие приложения не пропускает.
  - ✔ `yt-dlp` скачивается при включении расширения, как ffmpeg, и обновляется по кнопке — до версии, закреплённой в приложении (сумма из подписанного списка релиза; `yt-dlp -U` не используется).
  - ✔ При включении предупреждение: правила YouTube и других площадок запрещают скачивание без разрешения. Скачивать только своё или то, на что есть права.
  - ✔ Выбор качества или «только звук (mp3)» — mp3 и склейка дорожек через ffmpeg конвертера.
  - ✔ Ссылка в чате распознаётся фразой «скачай видео …». Адрес уходит только в `yt-dlp`, помощники и другие подключения его не видят.
  - Ограничение v1: deno не ставится — часть роликов YouTube может не скачаться (вопрос владельцу, ADR-024).
- **Общее:**
  - Разговорные фразы: «сконвертируй в mp3», «сожми в zip», «распакуй архив», «скачай видео по ссылке». Файл выбирается кнопкой «+».
  - Задачи идут в фоне: прогресс и отмена в карточке, по готовности — «Открыть папку».
  - Исходные файлы не меняются: результат кладётся рядом под новым именем.
  - Тяжёлые операции идут в отдельном процессе или изоляте, интерфейс не замирает.

- **Карточки-формы (решение владельца).** Команда («сконвертируй файл»,
  «скачай видео», «сожми в архив») или шаблон из «+» открывает в чате
  карточку расширения от Лиорио; поля, найденные во фразе, уже заполнены.
  - ✔ Конвертер: файл (выбрать или прикреплённый в сессии) → во что
    (выпадающий список по типу файла) → качество (только у подходящей
    цели, ADR-026) → «Запустить».
  - ✔ Загрузчик: ссылка → формат (видео с качеством или только звук) →
    «Скачать» (Windows, Linux).
  - Архиватор: файлы (на компьютере — перетащить в карточку, иначе
    проводник) → действие (создать архив / распаковать / посмотреть) →
    «Запустить».
  - После запуска — прогресс и «Отмена», по готовности «Открыть» и
    «Открыть папку». Одна общая карточка с полями расширения, чтобы
    будущие расширения вставали в тот же формат.
  - ✔ Общая карточка и архиватор сделаны (ADR-024, docs/EXTENSIONS.md,
    «Карточка-форма»); на телефоне «Открыть папку» нет — у результата
    только «Открыть».

## Библиотека голосовых профилей — после расширений

Расширение «Библиотека голосовых профилей», у каждого помощника настройка
«Голосовой профиль» (профиль, скорость, громкость). Задел под беседу
голосом.
- Встроенных голосов нет — приложение не тяжелеет; без профиля помощники
  отвечают текстом.
- Профиль — модель офлайн-синтеза (формат Piper, 20–60 МБ) и описание; ставится
  из файла. Недоверенный файл: проверка формата и размера, никакого
  исполняемого кода.
- Права: при первом импорте — короткое предупреждение использовать только
  голоса, на которые есть право. Если появится общая библиотека профилей
  (сайт): «Паки загружают пользователи; по запросу правообладателя пак
  удаляется из библиотеки», кнопка «Пожаловаться», контакт для
  правообладателей, автор подтверждает права при загрузке; удалённый пак у
  человека остаётся, но обновления больше не предлагаются.
- Название «Vocaloid» не используем — это торговая марка Yamaha.

## Подключение своих приложений к помощнику

Сейчас подключения работают по описанию `assistant/1`: его пишет автор приложения (у склада — `tools/assistant/gen.mjs`), а в «Связном» лежит встроенная копия, и она главная. Подключить новое приложение может только тот, чьё описание встроено в сборку. Цель — дать это любому человеку. Порядок: 1 → 2 → пакет → 3, после навыка «Пароли».

1. **Набор для разработчика.**
   - Спецификация формата `assistant/1` с примерами.
   - Проверка описания одной командой, отдельно от склада (вынести из `gen.mjs --check`).
   - Экран «Проверить описание» в «Связном»: какие фразы поймёт и что с ними сделает.
2. **Подключение по адресу.**
   - Человек вводит адрес приложения, где лежит `assistant.json`.
   - «Связной» показывает экран прав: какие данные читает, какие ключи нужны, есть ли запись.
   - После «Разрешить» описание сохраняется у человека и становится главным для этого подключения.
   - Новая версия с большими правами снова идёт на одобрение.
3. **Пакет адаптера** (один файл, например `.relay`).
   - Содержимое: `assistant.json`, фразы и корпус для проверки, тексты ответов в 4 стилях, значок и описание, при желании — подпись автора.
   - Импорт проверяется по тем же правилам и показывает экран прав.
4. **Мастер адаптеров** — для приложений без `assistant.json`.
   - На входе OpenAPI/Swagger, выгрузка Postman или примеры запросов.
   - Помощник собирает черновик: какие запросы только читают, какие фразы им подходят, как показать ответ.
   - Человек отмечает нужное, проверяет на тестовых фразах и сохраняет как свой адаптер.
   - Фразы можно улучшить локальными моделями (qwen, gemma) на компьютере, без отправки данных наружу.

**Правила для чужих подключений:**
- Только чтение. Действия с записью — только у встроенных подключений, по схеме «расчёт → карточка → Подтвердить».
- Адаптер не видит сейф паролей, задачи и другие подключения: только фразу, сказанную для него.
- Ключи хранятся как у склада и уходят только на адрес своего приложения.

## Память и отношения помощников

После истории чатов. Порядок: сначала Хранилище контекста, затем
отношения с помощниками, затем «настроение» помощника. Всё — только на
устройстве, всё выключается в «Настройки → Помощники».

- **Хранилище контекста** (не реализовано, план). Один файл на
  устройстве — `<документы>/assistant/context.json` (версия формата,
  атомарная запись, битый файл → `*.broken`, как у чатов): кто хозяин
  помощника, его идеи, мысли и заметки. Слово «Хранилище» в интерфейсе
  зарезервировано за этой функцией: менеджер паролей зовётся «Сейф»,
  экран места данных — «Данные».
  - *Постоянно дополняется* из разговора и из ответов на уточняющие
    вопросы: ответ «пароли» на «Копию чего: паролей или всех данных?» —
    естественный источник («обычно речь о паролях»).
  - *Явное:* «меня зовут Аня», «запомни, что я работаю до шести», «зови
    меня на ты», «запиши идею: …», «забудь, как меня зовут», «забудь
    всё». На «запомни» — короткое подтверждение, что именно запомнено;
    без подтверждения ничего не пишется.
  - *Выведенное из поведения* — только выше порога уверенности и числа
    наблюдений, с пометкой «предположение»: обычное время задач («утром»
    у этого пользователя — 8:00, а не 9:00), частые метки (#работа),
    любимый стиль и помощник. Догадка до порога не используется;
    использованная — объяснима («поставил на 8:00 — обычно вы так
    делаете») и отменяема.
  - *Экран «Хранилище контекста»:* описание хозяина, идеи, мысли и факты
    с источником (сказали / заметили / предположение), просмотр, правка,
    удаление по одному и «Забыть всё».
  - **Никогда не содержит паролей и секретов:** перед записью — тот же
    фильтр `SecretGuard`, что и для истории чата; фраза о паролях не
    попадает в файл ни целиком, ни частью.
  - Только на устройстве, без сети и отправки; входит в резервную копию
    «Данных».
- **Отношения с каждым помощником.** Уровень у Liorio и Noda свой:
  знакомство → приятели → близкие; растёт от взаимодействий (дни с
  разговором, выполненные вместе задачи), а не от времени.
  - Влияет **только на тон**: обращение по имени, вспомнить недавнее («как
    прошёл отчёт?»), серии («пятый день подряд закрываете всё»), свои
    шутки. Факты и команды на любом уровне одинаковы.
  - Отношение пользователя влияет на теплоту: «спасибо» — теплее, грубость
    — суше и спокойнее (как `talk.rude` сейчас), без обиды.
  - Реплики — записи каталога ответов с вариантами по уровню.
- **Лёгкий тамагочи.** Настроение помощника — из состояния задач
  пользователя (всё закрыто — довольный, много просроченных —
  озабоченный): видно в аватаре и кубике статуса. Вехи: первая неделя,
  сотая выполненная задача, месяц без просрочек.
- **Не делаем:**
  - не давим чувством вины («я расстроилась, что вы не закрыли задачу»);
  - не утверждаем, что у помощника настоящие чувства;
  - ничего не отнимаем и не «портим» за отсутствие: уровень не падает,
    настроение не наказывает, возвращение — просто «с возвращением»;
  - всё отключаемо: память, выводы из поведения, отношения, настроение —
    по отдельности.

## Потом

- **Жалобы на состояние сервера и коннектора с эскалацией.** Помощник с
  подтверждением отправляет жалобу редакторам приложения; если за 3–5 часов
  (настройка коннектора) никто не ответил — администратору. Отсчёт и
  эскалация — на сервере приложения (у halowarekeep — новое действие «принять
  жалобу»), а не в помощнике: закрытое приложение не должно терять жалобу.
  Требования к серверу — в `docs/CONNECTORS.md`, «Жалобы: что должен уметь
  сервер»; вопрос «Передать жалобу администратору?» уже задаёт «Как дела?».

- **Сделано — коннектор склада halowarekeep** (ADR-011, `ManifestConnector`):
  по описанию `assistant/1`, только чтение — «где лежит», «сколько», «что в
  ячейке», приходы за сегодня, вчера и неделю, приходы без фото, «сколько
  стоит» (честный ответ без сети), справка. Вход вставкой ссылки из «Войти на
  телефоне» или вручную (пароль склада, по желанию логин), выход с `sess_end`
  у склада 1.4.56. Дальше по складу:
  - **ссылки и переходы**: открывать артикул, ячейку и приход в складе
    (`links.*.url` в описании и разбор `#sku=`, `#cell=`, `#entry=` в складе);
  - карточка ответа чтения вместо строк текстом (`AssistantResponse.card`
    уже занят карточкой действия, ADR-013, — нужна своя модель);
  - секреты в Keychain/Keystore вместо файла (`SecretStore`, новая
    зависимость — отдельным ADR);
  - `http://` в своей сети на Android (`network_security_config`);
  - слот expeora тем же коннектором; `ask_backups` для «Контроля копий».
- **Сделано — действия с записью на складе** (ADR-013, склад 1.4.57):
  отметка проведения прихода и перемещение между ячейками — расчёт
  `act_*_check`, карточка, запись только по «Подтвердить», `act_settle` при
  неизвестном итоге; «Разрешить действия» в роли «Кладовщик» для одного
  логина. **Вторая очередь** (решения владельца, сейчас не делаем):
  - **отмена перемещения обратным документом**: кнопка «Отменить» под
    выполненной карточкой — новое перемещение `to → from` того же
    количества своим расчётом и карточкой, с проверкой, что строка в
    приёмнике ещё есть; пока ответ называет номер ПЕР-… для отката вручную;
  - **замок для ручных сохранений склада** (`ASSIST_LOCK_SET` на сервере):
    `set`/`delete` для `wh:(e|m|s):` берут тот же замок, что запись
    помощника, — закрывает окно гонки с интерфейсом склада в файловом
    режиме и затирание отметки проведения встречной записью формы;
  - правка маршрутизатора для глаголов задач («перенеси 3 стула из … в …»,
    «закрой приход 318» — сейчас `known_gap` в корпусе);
  - партии (`lot`) в карточке перемещения, многострочные перемещения,
    раскладка «БЕЗ МЕСТА», снятие отметок проведения — по запросу.
- **Описание приложения `assistant.json` и его генератор.** Приложение
  описывает свои команды, вход и API одним файлом (по образцу MCP); генератор
  составляет черновик по коду приложения, человек проверяет. Так подключаются
  expeora и чужие приложения без изменений в коде помощника. Сделано на
  стороне «Связного»: `ManifestConnector` читает такие описания (ADR-011);
  формат и генератор — у halowarekeep (`tools/assistant/`).

## Открытый проект и распространение

- **Лицензия — MPL-2.0** (`LICENSE`). Изменённые файлы самого помощника при
  распространении остаются открытыми; расширения, паки и сайты хостов — под
  любой лицензией. Чужие правки попадают в проект только пулл-реквестом с
  зелёным CI и одобрением владельца: ветка `main` защищена, корпус ловит
  поломки парсера до слияния.
- **Ядро отдельно от интерфейса.** Разбор фраз, коннекторы, навыки, паки и
  маршрутизатор — пакет `assistant_core` на чистом Dart без Flutter. Одно ядро
  — несколько «лиц».
- **Дистрибутив для хостов.** Другие приложения (halowarekeep, expeora,
  чужие) встраивают помощника:
  - веб — ядро, скомпилированное в JavaScript, и лёгкий чат-виджет
    (`<script>` + `<halo-assistant>`), сотни килобайт вместо мегабайт
    Flutter Web: быстро открывается при слабой сети, подхватывает стили
    хоста, текст выделяется и читается экранными чтецами;
  - внутри хоста помощник работает с правами текущего пользователя, без
    отдельного входа;
  - установка и обновление командой (`assistant install --host …`,
    `assistant update`): только подписанные сборки, каналы стабильный и
    тестовый, обновление подтверждает администратор хоста, есть откат;
  - своя версия под хоста: имя и личности, набор расширений и паков, свой
    коннектор.
- **Обратная связь по согласию.** «Не так» под ответом сохраняет фразу и
  правильный ответ на устройстве. Отправка — только при включённом
  «Помогать улучшать помощника» (по умолчанию выключен), после обезличивания
  (имена, числа, телефоны, адреса → заглушки) и показа того, что уйдёт.
  Дальше — обычный цикл генератора: два судьи, человек, корпус, выпуск.
- **Витрина расширений на expeora.** Пак, описание коннектора или форк
  публикуется карточкой с кнопкой «Добавить в помощника».
  - Сами паки бесплатны и открыты; авторов награждает Aerarium по
    использованию; «первый тираж» и рамки — коллекционная часть.
  - Дерево форков — в Иггдрасиле, со ссылкой на исходники каждой ветви.
  - На expeora — только данные (паки, `assistant.json`); код форков — в их
    репозиториях. Проверка тем же валидатором паков, модерация патрулём,
    жалобы, подпись автора; помощник предупреждает, если пак изменился после
    публикации.
  - Коннектор expeora в помощнике: «найди пак шуток про склад», «поставь пак
    …» (с подтверждением).
