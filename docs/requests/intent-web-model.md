# Промт для складов: «Модель понимания фраз» для веб-помощника «Связной»

Один промт для обоих складов. Скопируйте текст ниже в сессию Claude Code с
репозиторием склада:

- halowarekeep — `halogaloreontc/halowarekeep`, ветка
  `claude/tridot-assistant`;
- DepotDesk — `halogaloreontc/DepotDesk`, ветка `claude/tridot-assistant`
  (серверный код — в `server/`).

---

Работаем в репозитории склада на ветке `claude/tridot-assistant` (создай
от актуального `main`, если её нет; PR не открывай и в `main` не пушь, пока
я не попрошу). Прочитай CLAUDE.md и README склада и следуй им.

**Задача.** Веб-помощник «Связной» (Tridot, папка `assistant/` склада)
теперь умеет подсказывать команду, когда не понял фразу: «Похоже, вы
хотите найти непроведённые приходы?» → «Да» / «Нет» (Tridot, ADR-045, шаг
4). Модель работает целиком в браузере сотрудника (onnxruntime-web уже
лежит в архиве помощника), но саму модель (~32 МБ) помощник в себе не
несёт: её ставит склад, со своего адреса — CSP помощника пускает запросы
только к своему адресу. Нужен блок установки модели — по образцу установки
самого помощника (в halowarekeep — `assistweb.php`, в DepotDesk — его
аналог в `server/`).

Договор и устройство со стороны Tridot:
https://github.com/halogaloreontc/Tridot./blob/claude/nice-davinci-swz8vx/docs/WEB_WIDGET.md
(раздел «Понимание фраз») и ADR-045 в
https://github.com/halogaloreontc/Tridot./blob/claude/nice-davinci-swz8vx/docs/DECISIONS.md
(«Дополнение: шаг 4»). Прочитай оба перед началом.

### Договор путей (менять нельзя — его читает помощник)

```
<адрес склада>/assistant/intent/web/current.json          указатель
<адрес склада>/assistant/intent/web/<dir>/manifest.json   пакет версии
<адрес склада>/assistant/intent/web/<dir>/<файлы из manifest.json>
```

- `current.json`:
  `{"format": "tridot-intent-current/1", "tier": "web", "version": "1.0.0",
  "dir": "1.0.0-6dc650b6", "manifest_sha256": "<sha256 manifest.json>"}`.
  `dir` — `<версия>-<первые 8 знаков sha256 архива>`, только
  `[A-Za-z0-9][A-Za-z0-9._-]{0,63}`, рядом с указателем. Лишние поля
  можно (`size`, `installedAt`) — помощник их не читает.
- Нет модели — `current.json` нет (404). Помощник тогда работает как
  раньше. Страницу вместо файла (SPA-заглушка на 404) он тоже поймёт как
  «нет модели», но лучше честный 404.
- Папка версии после распаковки не меняется; указатель пишется через
  временный файл и `rename` — смена версии атомарна (как
  `assistant/current.json` + `assistant/v/<версия>/` у самого помощника).
- Помощник сам сверяет каждый файл с `manifest.json` (размер и sha256), а
  уровень — `web`. Склад тоже проверяет всё при установке (ниже): в
  браузер не должно уходить то, что не прошло проверку.

### Что сделать

**1. Блок в интерфейсе.** Управление → Инструменты → Помощник, под блоком
веб-помощника — «Модель понимания фраз». Только администратор (те же права,
что у установки помощника; сервер проверяет права сам). Показывает:
установлена ли модель, версия, размер, когда и кем поставлена. Кнопки:
- «Проверить» — читает
  `https://github.com/halogaloreontc/Tridot./releases/download/intent-latest/latest.json`
  и показывает версию и размер архива уровня `web` (и «Установлена та же
  версия», если так);
- «Установить» / «Обновить до N» — скачать, проверить, поставить (одно
  нажатие — решение администратора);
- «Удалить» — с подтверждением.
Пояснение одной строкой: «Модель работает в браузере сотрудника, фразы
никуда не отправляются. Подсказки можно выключить в помощнике: меню →
«Понимание фраз».» Новый код — отдельным модулем интерфейса и отдельным
PHP-файлом (например, `intentweb.php`), не в большие файлы.

**2. Чтение `latest.json`.** Формат `tridot-intent-latest/1`:
`{format, version, tiers: {web: {url, file, size, sha256, title,
base_model, base_license, threshold, k, dims, metrics}, light: …,
accurate: …}}`. Берём только `tiers.web`. Проверки:
- `format` — ровно `tridot-intent-latest/1`; `version` — `^\d{1,4}\.\d{1,4}\.\d{1,4}$`;
  `sha256` — 64 hex; `size` — число, не больше 64 МБ;
- `url` начинается с
  `https://github.com/halogaloreontc/Tridot./releases/download/`, без
  `..`, кончается на `.zip`;
- загрузка — те же правила, что у обновлений помощника (`awFetch` в
  halowarekeep): только https, без логина в адресе, не больше 5
  переадресаций, каждый шаг — https и наружу (`wkOutsideIps`: никаких
  внутренних и служебных адресов), хосты — только `github.com`,
  `objects.githubusercontent.com`, `release-assets.githubusercontent.com`;
  предел размера при скачивании (`latest.json` — 64 КБ, архив — `size` из
  `latest.json`, и больше 64 МБ — отказ сразу); тайм-ауты.

**3. Установка.**
1. Свободное место — не меньше 3 × `size`, иначе понятный отказ.
2. Архив — во временный файл в закрытой папке (`data/…` в halowarekeep, её
   аналог в DepotDesk), размер и sha256 — ровно как в `latest.json`.
3. Распаковка безопасно, в закрытую временную папку: не больше 16 записей;
   имя — только `^[A-Za-z0-9][A-Za-z0-9._-]{0,63}$`, без папок, `..`,
   `\`, ведущей `/`, без ссылок (внешние атрибуты zip — только обычный
   файл); расширения — только `json`, `onnx`, `bin`, `txt`; файл — не
   больше 64 МБ, всё вместе — не больше 96 МБ, сжатие — не больше 1:50
   (zip-бомба); распаковка потоком с подсчётом байтов, а не по заявленному
   размеру.
4. `manifest.json`: `format` = `tridot-intent/1`, `tier` = `web`,
   `version` = версии `latest.json`; есть `model.int8.onnx`, `index.bin`,
   `labels.json`, `tokenizer.json`; каждый файл из `files` — есть, размер и
   sha256 совпадают; лишних файлов нет. Не сошлось — всё удалить, отказ
   «Архив модели не прошёл проверку».
5. Папка — `assistant/intent/web/<версия>-<sha8>/` (переименованием из
   временной на той же файловой системе), затем `current.json` через
   временный файл и `rename`. Предыдущую версию оставь до следующей
   установки (сотрудник мог начать её скачивать), более старые удали.
   Состояние (версия, размер, кто, когда) — в закрытом файле состояния, как
   `data/.assist-web.json`.
6. Всё — под той же блокировкой, что установка помощника (или своей), два
   нажатия подряд не ставят дважды.

**4. Удаление.** Сначала `current.json`, потом папки версий и временные
файлы. Помощник после этого говорит «Склад её не поставил».

**5. Как отдаются файлы.** Папка `assistant/intent/` — только статические
файлы: `.htaccess` (Apache) как у `assistant/` — без индексов, PHP и CGI
не исполняются; типы — `.json` → `application/json`, `.onnx` и `.bin` →
`application/octet-stream`, `.txt` → `text/plain; charset=utf-8`
(`.wasm` здесь нет — onnxruntime-web лежит в папке помощника); `ETag`
включён (по умолчанию у Apache и Nginx); `current.json` —
`Cache-Control: no-cache`, папки версий — `public, max-age=31536000,
immutable` (помощник всё равно сверяет по ETag). Сжатие (`deflate`/`gzip`)
для `application/json` и `application/octet-stream` — по желанию. Для
Nginx — строки в README рядом с блоком помощника. Service worker склада не
должен перехватывать `/assistant/` (уже так — проверь).

**6. Проверки (Playwright / API).** Без сети: подставной `latest.json` и
архив — как в проверках обновления помощника (в halowarekeep —
`tests/specs/assist-web-*.spec.mjs` и `assist-web-helpers.mjs`; свой zip
без сжатия позволяет сделать «плохие» архивы). Пакет — синтетический
(маленькие файлы и манифест с их суммами), не настоящая модель. Проверь:
- установка → `current.json` с нужными полями, файлы на месте и отдаются с
  нужными типами и ETag, `current.json` — `no-cache`;
- повторная установка той же версии ничего не ломает; новая версия —
  указатель переключился, старая папка осталась, позапрошлая удалена;
- отказы: sha256 архива или размер не те; `url` не с выпусков Tridot;
  переадресация на http или на внутренний адрес; больше 5 переадресаций;
  в архиве `../x`, папка, ссылка, лишний файл, `.php`; файл не совпал с
  манифестом; `tier` не `web`; версия манифеста не та; zip-бомба;
- без прав администратора — 403, кнопок нет;
- «Удалить» → `current.json` 404;
- `php -l` и все проверки репозитория (CLAUDE.md).

**7. Документы.** README (раздел помощника): что за модель, где лежит,
сколько места, как поставить и удалить, строки Nginx; запись в CHANGELOG,
версия — по правилам репозитория.

### Чего не делать

- Не читать, не печатать и не коммитить `config.php`, `.env*`, `data/`,
  ключи и токены; в тестах — только заведомо поддельные значения.
- Не скачивать модель из других мест, кроме выпусков Tridot, и не ставить
  то, что не прошло проверку.
- Не класть ничего исполняемого в `assistant/intent/`, не отдавать оттуда
  листинг папки.
- Не менять договор путей и формат `current.json`, `postMessage` и
  установку самого помощника.
- Не отправлять на сервер фразы сотрудников: модель и всё, что она
  выучила, живут только в браузере.

В конце: что сделано, версия склада, новые действия API, как выглядит
блок (снимок), результаты проверок.
