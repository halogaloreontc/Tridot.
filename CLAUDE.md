# Tridot «Связной» — правила для работы с кодом

Офлайн-помощник на Flutter без нейросети: всё понимание — правила,
словари и корпус фраз. С владельцем пишем по-русски; комментарии в коде,
документация и тексты интерфейса — по-русски.

Документация: `docs/ARCHITECTURE.md` (устройство), `docs/CONNECTORS.md`
(коннекторы и описание `assistant/1`), `docs/EXTENSIONS.md`,
`docs/REPLIES.md` (каталог ответов), `docs/CORPUS.md` (корпус фраз),
`docs/WEB_WIDGET.md` (веб-помощник на складе), `docs/ASSISTANT_HELP.md`
(договор справки и документов с приложениями), `docs/DECISIONS.md` (ADR —
перед изменением поведения прочитай связанные).

## Слои

```
lib/core        чистый Dart без Flutter: разбор фраз, коннекторы, задачи,
                чаты, хранилища за интерфейсами
lib/app         интерфейс Flutter: экраны, оболочка, виджеты
lib/web_widget  веб-помощник склада (flutter build web -t lib/web_widget/main.dart)
```

- `lib/core` не импортирует `lib/app` и Flutter-виджеты.
- Веб-помощник не тянет `dart:ffi`, `path_provider`, `file_selector`,
  `mobile_scanner`, `record`, `dart:io` на пути склада — следит
  `test/web_widget/web_graph_test.dart`. Нужна часть приложения в помощнике
  — вынеси её в отдельный файл без лишних импортов (так сделаны
  `message_row.dart`, `composer_shell.dart`, `persona_mark.dart`).
- `lib/app/home_page.dart` большой: новое — отдельным виджетом в
  `lib/app/widgets/` или `lib/app/shell/`, а не в него.

## Распознавание

- Все слои разбора — один модуль `RecognitionLayers`
  (`lib/core/scenario/recognition_layers.dart`, ADR-037): контроллер,
  тест корпуса и инструменты зовут его, а не свои копии.
- Новая фраза или исправление — сначала строка в `test/corpus/*.jsonl`,
  потом код. После правки корпуса — `dart run tool/gen_lexicon.dart`.
- `known_gap` в корпусе — честный пробел, а не способ сделать тест
  зелёным.
- Приватные фразы (пароль, PIN, код, логин) не исправляются, не уходят в
  сеть и в коннекторы.

## Проверки перед коммитом

```bash
export PATH=/opt/flutter/bin:$PATH
dart format --output=none --set-exit-if-changed lib test tool
flutter analyze                    # info и warning тоже валят CI
flutter test --no-pub              # ~8,5 тыс. тестов, ~7 минут
dart run tool/gen_lexicon.dart     # если менялся корпус
tools/corpus_gen/.venv/bin/python -m pytest -q   # если менялся corpus_gen
```

Полный прогон на занятой машине лучше гонять в отдельной копии
(`git worktree`), иначе правки под рукой попадают в прогон.

## Нельзя

- Ключи API — только в переменных окружения, не в настройках и не в
  репозитории. Ключ издателя, ключи бакета, токены — не печатать и не
  коммитить.
- Пароли, PIN, коды восстановления — ни в историю чата, ни в логи,
  уведомления, корпус, имена тестов и снимки: только синтетические
  значения (CANARY).
- В модели генерации корпуса — только синтетические фразы, не задачи
  пользователя.
- Голос распознаётся только на устройстве.
- Действия на запись во внешних приложениях — только с подтверждением.
- Идентификаторы моделей ИИ — не в коде, не в документации и не в
  описаниях; только в строке соавторства коммита.
