# Замеры «Продвинутой» — генеративная модель на устройстве (ADR-046, шаг 1)

Кандидаты — Qwen в GGUF Q4_K_M (`config.py`: ревизия и sha256
закреплены). Здесь только замеры: какая модель годится и для чего. Пакет
для приложения и выпуск — следующие шаги.

## Собрать у себя

```bash
python3 -m venv .venv-gen
CMAKE_ARGS="-DGGML_NATIVE=ON" .venv-gen/bin/pip install -r tools/gen_model/requirements.txt
.venv-gen/bin/python -m tools.gen_model fetch  --model qwen3-1.7b
.venv-gen/bin/python -m tools.gen_model intent --model qwen3-1.7b            # без примеров
.venv-gen/bin/python -m tools.gen_model intent --model qwen3-1.7b --shots 3  # 3 фразы на команду
.venv-gen/bin/python -m tools.gen_model bench  --model qwen3-1.7b
.venv-gen/bin/python -m pytest -q tools/gen_model/tests
```

Запускать из корня репозитория: примеры берутся из снимков корпуса в
истории git. Модели — в `~/.cache/tridot-gen` (`GEN_MODEL_CACHE`),
результаты — `tools/gen_model/out/<модель>/` (в git не попадают).

## Подсказка при «не понял»

- **Пробы и метрики — те же, что у «Лёгкой»** (`tools/intent_model`):
  fresh, held2, held3; `catch`, `wrong_of_suggested`, `false_alarm`;
  бюджет — не больше 6 % неверных подсказок и 5 % ложных тревог. Порог
  подбирается на fresh, проверка — held2 + held3. Прогоняются фразы,
  которых правила не поняли, и «не команды» (344 фразы).
- **Вывод ограничен списком меток** (`choose.py`): метки и `none`
  токенизируются в дерево, на каждом шаге разрешены только продолжения из
  него. Уверенность — произведение вероятностей шагов, перенормированных
  по разрешённым токенам.
- **Честность.** В запросе — описания команд из `labels.yaml`. С
  `--shots N` — ещё N фраз на команду из снимка корпуса до разбора пробы;
  фразы снимка, похожие на фразы пробы, убираются тем же правилом, что у
  «Лёгкой».

## Что получилось (2026-11-25)

CPU контейнера: 4 ядра x86, 4 потока; телефон будет медленнее.
«В бюджете» — есть ли порог, при котором уложились в бюджет ошибок.

| модель | примеры | поймано (без порога) | неверных из подсказок | ложные тревоги | в бюджете | фраза, медиана |
|---|---|---|---|---|---|---|
| «Лёгкая» (USER-base, kNN; для сравнения) | корпус | 38,3 % | 3,5 % | 3,1 % | да, порог 0,895 | 8,5 мс |
| Qwen2.5-1.5B | нет | 43,9 % | 56,1 % | 93,1 % | порог 0,99: 3,7 % поймано | 0,24 с |
| Qwen3-1.7B | нет | 17,3 % | 47,1 % | 23,1 % | нет | 0,24 с |
| Qwen3-1.7B | 3 | 30,8 % | 36,5 % | 17,7 % | нет | 0,40 с |
| Qwen3-4B-Instruct-2507 | нет | 65,9 % | 31,9 % | 63,1 % | нет | 0,63 с |
| Qwen3-4B-Instruct-2507 | 3 | **77,1 %** | 18,3 % | 53,8 % | нет | 0,95 с |

Скорость и память (`bench`, запрос 67 токенов, жадная генерация):

| модель | файл | память процесса | разбор запроса | генерация |
|---|---|---|---|---|
| Qwen2.5-1.5B | 1,1 ГБ | 2,2 ГБ | 215 ток/с | 19 ток/с |
| Qwen3-1.7B | 1,1 ГБ | 2,8 ГБ | 137 ток/с | 15 ток/с |
| Qwen3-4B-Instruct-2507 | 2,5 ГБ | 5,7 ГБ | 75 ток/с | 8 ток/с |

Память — с контекстом 4096 токенов. Системный запрос с описаниями команд
(934 токена, с примерами — 3303) прогоняется один раз и кэшируется.

**Выводы.**

- Qwen3-4B с примерами чаще всех угадывает команду: 77 % того, что не
  поняли правила, против 38 % у «Лёгкой». Но она слишком уверена в себе:
  «не команды» («через полтора часа поезд», «а пятница у нас какого
  числа») получают метку с уверенностью ~1,0. Ложных тревог 54 %, и
  никакой порог по уверенности не укладывает их в бюджет.
- Малые модели (1.5B, 1.7B) хуже «Лёгкой» по всем метрикам.
- Значит, **сама по себе** генеративная модель для этой подсказки не
  годится. Следующий опыт — согласие двух слоёв: подсказка, только если
  метка Qwen есть среди ближайших меток «Лёгкой» (её kNN уже отсекает
  «не команды»). Для него нужны векторы проб «Лёгкой» (`tools/intent_model`,
  шаг `holdout`).
- Пересказ по-русски Qwen3-1.7B пишет связно (`bench`, пример в
  `out/<модель>/bench.json`). Таблицы, поля и пересказ — свои пробы на
  следующих шагах.
